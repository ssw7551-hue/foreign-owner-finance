# 데이터 검수 결과 (2026-11-15)

대상: `data/raw/kosis/`의 KOSIS 통계표 27개(이민자체류실태및고용조사)와 분석에 필요한 나머지 자료.
검수 방법: 행 중복·빈 값·연도 빠짐·음수·합계 일치·표 사이 일치를 코드로 확인했다. 내용은 타겟(외국인 사장님) 근거로 쓸 수 있는지로 판정했다.

## 1. 품질 검사 (27개 표 공통)
| 검사 | 결과 |
|---|---|
| 중복 행 | 27개 모두 0건 |
| 음수·이상값 | 0건 |
| 빈 값 | 9개 표에 소수 있다(최대 2.9%). 모두 원자료의 `-`(해당 없음·표본 없음)이고 분류가 생기기 전 연도이거나 소규모 국적이다 |
| 구성 항목 합 = 합계 | 7개 표 확인, 차이 최대 0.2천 명(반올림) |

| 표 사이 일치 | 취업자 합계(3개 표), 15세 이상 인구(2개 표)가 서로 0.0천 명 차이로 같다 |
| 보도자료와 일치 | 손으로 옮긴 값 110개, 체류자격별 표, 자녀 표가 모두 반올림 범위 안에서 같다 (`tests/test_api.py`) |

주의할 점
- **신뢰도 표시가 빠진다**: KOSIS 화면에는 상대표준오차가 큰 값에 `*`·`**`가 붙지만 API 자료에는 표시가 없다. 값이 작은 칸(예: 1천 명 안팎, 소규모 국적·체류자격)은 오차가 크다고 보고 근거로 쓰지 않는다.
- **한 표 안에 '계'·'기타'가 여러 번 나온다**: 성별·체류자격·국적·지역 묶음이 한 표에 같이 들어 있다. `load.kosis_wide`가 분류 코드로 구분하도록 고쳤고, 값이 겹치면 평균을 내지 않고 오류를 낸다. 고치기 전후로 분석 숫자는 같다.
- **분류가 중간에 바뀐 표가 있다**: 최초 입국시점(연도 구간이 해마다 달라진다), 거주지역(인천·경기 분리는 최근 연도만), 국적(캄보디아·네팔은 2017년부터).
