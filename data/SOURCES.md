## 새로 받아오기 (`python -m src.refresh` 또는 API `POST /data/refresh`)
- 한국은행 ECOS·World Bank: 받은 내용이 지금 파일과 다를 때만 `raw/fx/ecos_731Y004_<코드>_YYYYMMDD.jsonl`, `raw/worldbank/<이름>_YYYYMMDD.json`으로 저장한다. 처음 받은 파일은 그대로 둔다. 로더는 날짜가 가장 늦은 파일을 읽는다.
- 법무부: 게시판(https://www.moj.go.kr/immigration/1569/subview.do)에서 지금 가진 것보다 새 달의 '체류외국인 원본 통계표'와 '지역별 외국인(등록+거소) 현황' 엑셀만 `raw/moj/new/`에 받는다. 분석은 `raw/moj/` 바로 아래 파일만 읽는다.
- 2026-11-14 실행 결과: 세 곳 모두 응답했고 새로 나온 자료는 없었다 (환율 2026.10, 송금 2025, 법무부 2026.9가 최신).
- 통계청 KOSIS(`python -m src.refresh kosis`): 「이민자체류실태및고용조사(상주인구기준)」 통계표 16개를 `raw/kosis/<표ID>_YYYYMMDD.json`으로 받는다. 표 목록은 `src/refresh.py`의 `KOSIS_TABLES`, 원문은 `https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=<표ID>`다. 인증키는 `F1/.env`의 `KOSIS_API_KEY`에 두고 코드·문서에 적지 않는다. 2026-11-15에 처음 받았다(최신 2025년).
  - 종사상 지위별 취업자(DT_2FB007F)는 2012~2025년, 소수 첫째 자리(천 명)까지 나온다. 외국인 자영업자는 2012년 1.92만 명 → 2025년 5.59만 명이다. `curated/survey_immigrants.csv`의 2022~2025년 값(반올림)과 일치한다.
  - 공개표의 종사상지위는 성별로만 나뉜다. 체류자격별·국적별 자영업자 수는 KOSIS에 없으므로 MDIS 마이크로데이터가 필요하다.
  - 소득·지출·송금·경제적 어려움 표는 2년 주기(2017~2025)다.
  - 2026-11-15에 표 11개를 더 받아 모두 27개다(국적별 경제활동, 거주지역별 취업자, 사업체 규모, 근속기간, 국민연금·건강보험 가입, 최초 입국시점, 체류자격 변경, 배우자, 소득 만족도, 한국생활 어려움).
  - 분석은 이제 KOSIS 값을 읽는다(`load.load_survey`, `load_survey_by_visa`, `load_children`). `curated/`의 손으로 옮긴 값 110개와 체류자격별·자녀 표는 KOSIS와 반올림 범위 안에서 모두 일치했다. 체류자격별 소득 분포(`survey_by_visa_2025.csv`의 inc_* 열)만 KOSIS 공개표에 없어 보도자료 값을 계속 쓴다.
- `raw/kosis/체류자격별_경제활동인구_외국인__20261115194224.csv`: 사용자가 KOSIS 화면에서 직접 받은 파일이다(DT_2FA002F와 같은 표).
